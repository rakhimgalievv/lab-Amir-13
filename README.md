# Лабораторная работа №13 — Коллекции и структуры данных (Python)

## Состав
- `shopping_list.py` — вариант 1, базовый: список покупок, добавление/удаление/просмотр, обработка отсутствующего товара.
- `orders_queue.py` — вариант 8, средний: очередь заказов на `collections.deque`, выдача FIFO, поиск, отчет.
- `routes_bfs.py` — вариант 19, повышенный: кратчайший путь в невзвешенном графе алгоритмом BFS на `deque`.
- `report.docx` — отчет с постановкой задач, алгоритмами, кодом, тестированием и ответами на контрольные вопросы.
- `tests/test_results.txt` — результаты проверок.

## Запуск
Требуется Python 3.10+; сторонние библиотеки для программ не нужны.

```bash
python shopping_list.py
python orders_queue.py
python routes_bfs.py
```

## Творческое задание
Во всех трех программах реализовано сохранение данных в JSON. Для BFS дополнительно сохраняется описание графа; в системе заказов сохраняются очередь и завершенные заказы. Выбор JSON обоснован тем, что структура данных естественно представляется списком/словарем, формат читаем человеком и поддерживается стандартным модулем `json`.

## Тесты
В `tests/test_results.txt` приведены контрольные сценарии: обычная работа, пустая коллекция, дубликат, отсутствующий элемент и граничный случай.
